# تطبيق قائمة مارفل — Doomsday

هذا مشروع Android Studio يحوّل موقع قائمة مارفل إلى تطبيق أندرويد يعمل دون إنترنت. يحتفظ بالتصميم الأخضر الداكن وشعار MARVEL، والبحث والتصفية وعلامات المشاهدة ونسبة التقدم. يتم حفظ التحديدات محليًا داخل التطبيق عبر WebView Local Storage.

## بناء ملف APK

1. افتح مشروع `MarvelDoomsday` في Android Studio على كمبيوتر.
2. اسمح لـ Android Studio بتنزيل مكونات Android SDK المطلوبة (API 35) وGradle عند الطلب.
3. من القائمة اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. بعد اكتمال البناء، اضغط **locate** أو ابحث عن الملف هنا:
   `app/build/outputs/apk/debug/app-debug.apk`
5. انقل ملف APK إلى الهاتف وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## ملاحظات

- `minSdk 23` يعني Android 6.0 أو أحدث.
- القائمة محلية ولا تحتاج اتصالًا بالإنترنت بعد تثبيت التطبيق.
- المشروع يحتوي صفحة الموقع في `app/src/main/assets/index.html`.
